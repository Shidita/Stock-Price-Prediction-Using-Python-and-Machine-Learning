# Stock Price Prediction Using Python and Machine Learning

## 📌 Project Overview

This project is a **Stock Price Prediction System** developed using Python and Machine Learning. The application analyses stock-market data and predicts an estimated closing price based on selected market parameters.

The project is designed as an academic mini project to demonstrate the practical application of **Machine Learning, data analysis, Python programming, and web application development**.

## 🎯 Objectives

- Analyse historical stock-market data.
- Understand stock price trends and patterns.
- Use Machine Learning for price prediction.
- Predict an estimated closing price.
- Provide a simple and interactive web interface.
- Demonstrate the practical use of Python in financial data analysis.

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **NumPy**
- **Scikit-learn**
- **Ridge Regression**
- **yfinance**
- **Flask**
- **HTML**
- **CSS**
- **JavaScript**

## 📊 Data Source

The project uses **Yahoo Finance** data through the `yfinance` Python library.

The main market parameters used include:

- Open Price
- High Price
- Low Price
- Volume
- Closing Price

## 🤖 Machine Learning Model

The project uses **Ridge Regression** for stock-price prediction.

Ridge Regression is a regularized form of Linear Regression that helps reduce overfitting by applying L2 regularization.

The model uses market parameters as input features and predicts the estimated **closing price**.

## 🌐 Web Application

The project uses **Flask** to provide a web-based interface.

Users can:

1. Select a stock ticker.
2. Load or enter market data.
3. View stock-price information.
4. Enter Open, High, Low and Volume values.
5. Predict the estimated closing price.
6. View recent prediction results.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/stock-price-prediction.git
```

Go to the project folder:

```bash
cd stock-price-prediction
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

The application will normally be available at:

```text
http://127.0.0.1:5000
```
